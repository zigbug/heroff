# Dungeons & Dragons App

Приложение для создания и управления персонажами в игре Dungeons & Dragons.

## Архитектура проекта

Проект организован по принципам Clean Architecture и разделен на следующие слои:

### Структура папок

```
lib/
├── models/              # Модели данных
│   └── character.dart   # Модель персонажа
│
├── screens/             # Экраны приложения
│   └── character_creation_page.dart  # Экран создания персонажа
│
├── widgets/             # Пользовательские виджеты
│   └── progress_indicator.dart       # Индикатор прогресса
│
├── repositories/        # Репозитории данных
│   └── character_repository.dart     # Репозиторий персонажей
│
├── services/            # Сервисы
│   └── camera_service.dart           # Сервис работы с камерой
│
├── utils/               # Вспомогательные классы и константы
│   └── constants.dart               # Константы приложения
│
└── theme.dart           # Темы приложения
```

### Описание слоев

1. **Models** - Содержит все модели данных приложения. Модели должны быть чистыми классами без зависимостей от других слоев.

2. **Screens** - Экраны приложения. Содержат логику отображения и взаимодействия с пользователем. Взаимодействуют с репозиториями и сервисами.

3. **Widgets** - Пользовательские виджеты, которые могут использоваться на разных экранах. Должны быть переиспользуемыми и независимыми.

4. **Repositories** - Интерфейсы и реализации репозиториев для работы с данными. Слой абстрагирует источники данных (базы данных, API и т.д.).

5. **Services** - Сервисы для выполнения специфичных задач, таких как работа с камерой, сетевые запросы и т.д.

6. **Utils** - Вспомогательные классы, константы и утилиты.

7. **Theme** - Файл с темами приложения, содержащий цветовые схемы и стили.

## Зависимости

- flutter_bloc: ^8.1.3 - Для управления состоянием приложения
- image_picker: ^1.1.2 - Для работы с камерой и выбора фото
- camera: ^0.10.6 - Для прямой работы с камерой устройства

## Настройка разрешений

Для работы с камерой необходимо добавить следующие разрешения в манифесты:

### Android (android/app/src/main/AndroidManifest.xml)
```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-feature android:name="android.hardware.camera" android:required="true" />
```

### iOS (ios/Runner/Info.plist)
```xml
<key>NSCameraUsageDescription</key>
<string>Это приложение использует камеру для создания фото персонажей</string>
```

## Использование

1. Запустите приложение
2. Перейдите на экран создания персонажа
3. Введите имя персонажа
4. Сделайте фото персонажа
5. Сохраните созданного персонажа

## Разработка

При разработке рекомендуется следовать следующим принципам:
- Все экраны должны быть независимыми
- Модели данных не должны содержать бизнес-логики
- Сервисы должны быть легко тестируемыми
- Все зависимости должны передаваться через конструкторы
